# 💳 Simulador de Cartão de Crédito - Java

Este é um projeto Java que simula o uso de um cartão de crédito, permitindo ao usuário lançar compras, verificar saldo restante e visualizar um extrato final ordenado por valor.

## 🔖 Sobre
Projeto desenvolvido com o objetivo de praticar lógica de programação orientada a objetos, uso de listas, ordenação e interação via terminal com o usuário.

## 🔥 Funcionalidades
- Lançamento de compras com descrição e valor.
- Verificação automática de saldo antes de cada compra.
- Armazenamento e ordenação das compras realizadas.
- Exibição do saldo restante do cartão ao final.

```
